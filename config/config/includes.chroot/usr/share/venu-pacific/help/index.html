Venu Pacific — Help & Feedback

Version @VENU_VERSION@ · built on Debian 13

Venu Pacific is a free computer system made for Pacific island schools, families, and communities. Everything important works without the internet.

Found a problem?

Telling us about problems is the most helpful thing you can do — it is how this system gets better. Please tell your school's IT coordinator, or email:

suabiut@gmail.com

If you have internet access you can also report at github.com/sabiut/venu-pacific/issues.

When you report a problem, please include:

  • The version — it is at the top of this page (@VENU_VERSION@)
  • Which app — for example the Assistant, Learn, or the installer
  • What you did, what you expected, and what happened instead
  • A photo of the screen if there is an error message

What's on this computer

  • Ask (AI Assistant) — questions, translation, and help with the computer, fully offline. It can be wrong: for anything official, use the two apps below.
  • Safety (Disaster Readiness) — cyclone, earthquake, tsunami, and volcano guidance with real emergency numbers
  • Services Directory — how to get passports, certificates, licenses; hospitals and schools contacts
  • Learn (Kolibri) — offline courses and lessons. Content packs are downloaded separately by your school or coordinator.
  • Encyclopedia (Vikidia) — offline encyclopedia written for ages 8–13
  • LibreOffice, GIMP, Firefox — documents, images, and the web (when you have internet)

The easiest place to start is the Venu Pacific Hub in the applications menu — it has one button for each of these.

Common questions

  • The Assistant takes a minute to get ready after turning the computer on. That is normal — it is loading a large language model. It only happens once per session.
  • Does the Assistant send my questions to the internet? No. It runs completely on this computer. The only exception is if you ask it to search the internet and approve it when it asks.
  • Something says "disk is full". Free space by emptying the Trash and deleting large files you no longer need from Downloads.
